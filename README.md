# WHITE — Website

موقع تعريفي ثابت لوكالة WHITE، باللغتين العربية والإنجليزية. لا يحتاج إلى سيرفر أو قاعدة بيانات أو عملية بناء.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو ارفع محتويات هذا المجلد إلى مستودع GitHub.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع جميع الملفات والمجلدات كما هي، مع وجود `index.html` في الجذر.
3. من **Settings → Pages** اختر **Deploy from a branch**.
4. اختر فرع `main` ومجلد `/ (root)` ثم اضغط **Save**.

بعدها سيظهر رابط الموقع في صفحة GitHub Pages الخاصة بالمستودع.

## تعديل التواصل

روابط التواصل المستخدمة في الموقع:

- البريد: `info@whiteagn.com` (عنوان مقترح؛ تأكد منه قبل النشر إذا كان لديكم بريد مختلف)
- الموقع: `https://whiteagn.com`
- Instagram: `https://www.instagram.com/white.agency.oman/`

لم نضع رقم هاتف أو رابطًا اجتماعيًا آخر غير مؤكد. يمكن تعديل بيانات التواصل مباشرة من `index.html`.

## الصور والخط

الصور داخل `assets/` مستخرجة من ملف WHITE التعريفي المرفق. الخط Zain يُحمّل من Google Fonts، لذلك يحتاج اتصال إنترنت لعرضه؛ توجد خطوط احتياطية في حال عدم توفره.
